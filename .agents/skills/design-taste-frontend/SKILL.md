# Design taste

Audit the current interface before changing it. Choose a coherent visual direction tied to the product workflow. Avoid template-like card sprawl, gratuitous gradients, arbitrary rounded containers, weak hierarchy, and decorative motion. Preserve operational density and accessibility. Validate at real viewports and with the repository’s design system.
