# Frontend design

Inspect existing components, tokens, data contracts, and responsive behavior before editing. Build the usable workflow first. Preserve the project’s `DatasetProvider`, `getValue`, EvilCharts, `cn`, sticky-column, no-data, and sheet-root rules from `AGENTS.md`.

Check hierarchy, density, keyboard focus, loading/error/empty states, overflow, contrast, reduced motion, and mobile layouts. Prefer existing primitives over new dependencies. Validate with typecheck, tests, build, and real viewport evidence when applicable.
