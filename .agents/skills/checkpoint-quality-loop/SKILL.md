# Checkpoint quality loop

Create or reuse a goal for the checkpoint. Anchor repo, branch, dirty state, route, data store, deploy surface, and included/excluded lenses.

Audit confirmed findings, plan remediation, implement bounded slices, re-audit, and run acceptance review. Do not close on an audit, a plan, or passing tests alone. Separate local, browser, live, deploy, pushed, and blocked evidence.

Required closeout: checkpoint contract, audit receipt, planning receipt, implementation receipt, engineering acceptance receipt, verification receipt, accepted risks, and exact blockers. Verdict must be `checkpoint passed`, `passed with accepted risks`, `failed`, or `blocked`.
