# Visual QA

Run the app using repository instructions. Check desktop and narrow mobile viewports, loading/empty/error/data states, focus order, dialogs, sticky regions, text wrapping, and horizontal overflow. Capture observable evidence from the rendered route. Do not call a screenshot or local smoke test production proof.

Clean up servers, ports, browser contexts, and temporary files. Report exact routes, viewports, states, evidence, and unverified live/deploy gaps.
