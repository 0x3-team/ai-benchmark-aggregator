# Engineering acceptance review

Review goal fit, task fit, source ownership, contracts, maintainability, tests, rendered behavior, security/data risk, and evidence. Findings come first, ordered by severity. Separate local validation from live, deployment, and production claims. Return `accept`, `rework`, or `block` with exact evidence.
