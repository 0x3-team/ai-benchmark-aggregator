# Motion opportunities

Inspect existing states and transitions. For each candidate, state purpose, trigger, property, timing, easing, reduced-motion behavior, and risk. Reject motion that delays reading, hides state, distracts from benchmark data, or harms keyboard and screen-reader workflows.
