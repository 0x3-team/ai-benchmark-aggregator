# UI library selection

Start with existing project dependencies and architectural rules. Compare task fit, accessibility, maintenance, bundle cost, license, SSR/runtime fit, and migration cost. Prefer the smallest proven addition. For charts in this project, use EvilCharts and its adapters; do not introduce hand-rolled chart primitives.
